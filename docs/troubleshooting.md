# 排障

## 没有声音

按顺序检查：

1. **设置 → 提醒 → 启用提醒语音** 是否打开。ClassIsland 默认关着，不开只有画面。
2. **设置 → 提醒 → 提醒管理 → 远程播报**：如果这里开了「对此提醒来源启用特殊高级设置」，它以本条自己的「启用提醒语音」为准，而这个子开关默认是关的。不需要差异化就别开高级设置。
3. 播报内容是「遮罩段不发声 + 正文段发声」，这是故意的，避免同一句话念两遍。
4. 念出来用的是宿主选定的语音引擎。Edge TTS 连不上、429、合成超时都发生在宿主里，插件看不到——去 **设置页 → 错误日志 → 打开 ClassIsland 日志目录** 查。

## 端口被占用

设置页会显示「端口 8765 暂时被其他程序占用，正在自动重试」。服务会在后台按 1 秒到 15 秒的退避持续重绑，占用方一让开就恢复，不用重启 ClassIsland。

想立刻恢复就换一个端口。注意 Windows 有些端口段被系统保留（`netsh interface ipv4 show excludedportrange protocol=tcp` 可以查），撞上了换端口即可。

## 其他设备连不上

这是设计如此：服务只绑定 `localhost` 和 `127.0.0.1`，局域网里的其他机器连不上。需要跨设备时，用反向代理或内网穿透把请求转到本机 `8765`。

## 取景拍不出图

`GET /snapshot` 回 `503` 时，`error` 里就是原因，设置页的「试拍一张」也会把同一句话显示出来：

- **系统已禁止桌面应用访问摄像头** — 去 设置 → 隐私和安全 → 相机，打开「让桌面应用访问相机」。这一条是整个系统级的开关，ClassIsland 关了它就没戏。
- **摄像头正在被其他程序使用 / 没有出画面** — 视频会议、直播、相机类软件占着设备。本插件用共享模式，不会去抢，关掉对方或等它释放。
- **没有检测到能出画面的摄像头** — 没插、驱动没起来，或者只有红外/深度这类不出彩色画面的设备。
- **上一次取景还没结束** — 拍一张约 1.3 秒，同一时刻只服务一个请求。网页轮询请把这个间隔放到 2 秒以上。

画面选错了（比如拍出来是讲台上的实物展台）就在设置页的「摄像头」下拉里点名要哪一台，选完记住。「自动」这一档跟的是 Windows 的系统默认摄像头，系统没设默认时取列表里第一台。

## 取景的图会不会堆在硬盘上

不会。`GET /snapshot` 那张图在内存里编成 JPEG 直接写进 HTTP 响应，插件不落盘、不留临时文件——调用一百次，硬盘上也不会多一个字节。

只有设置页的「试拍一张」会写文件，而且固定就那一个路径、每次覆盖：`%TEMP%\RemoteSpeak 试拍.jpg`。占用上限是一张图（720 档约 227 KB），点「删除试拍图」即可清零；想确认位置就点「打开所在文件夹」。图片还开在查看器里时删不掉，关掉查看器再点一次。

## 日志在哪

设置页的「日志」栏默认展开，直接显示流水：每条请求一行——方法、路径、状态码；播报多带字数和正文前 20 字，取景多带设备、尺寸、大小和耗时；`GET /health` 一秒内的重复只留一行。错误（401/400/404/405/413/503/500、监听中断、发送异常）永远记，不受开关影响。

- 文件位置：ClassIsland 插件配置目录下的 `error.log`（文件名沿用历史，里面现在也记正常请求）
- 设置页 → 日志 → **打开日志文件** / **打开 ClassIsland 日志目录**
- 最多保留 300 条，新的在前；不想记流水就在「记录正常请求」里关掉
- `X-Token` 头永远不进日志
- 网页轮询取景时列表滚得很快，这是正常的；要留证据就趁还没被挤掉时点「打开日志文件」复制走

## 返回 500

响应里会带异常类型和原因，比如：

```json
{ "ok": false, "error": "内部错误：InvalidOperationException ..." }
```

同样的内容会写进插件错误日志。宿主语音服务内部的失败（Edge TTS 超时等）不会出现在这里，要去 ClassIsland 自己的日志里查。
