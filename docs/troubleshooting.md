# 排障

## 没有声音

按顺序检查：

1. **设置 → 提醒 → 启用提醒语音** 是否打开。ClassIsland 默认关着，不开只有画面。
2. **设置 → 提醒 → 提醒管理 → 远程播报**：如果这里开了「对此提醒来源启用特殊高级设置」，它以本条自己的「启用提醒语音」为准，而这个子开关默认是关的。不需要差异化就别开高级设置。
3. 播报内容是「遮罩段不发声 + 正文段发声」，这是故意的，避免同一句话念两遍。
4. 念出来用的是宿主选定的语音引擎。Edge TTS 连不上、429、合成超时都发生在宿主里，插件看不到——去 **设置页 → 错误日志 → 打开 ClassIsland 日志目录** 查。

## 端口被占用

设置页会显示「端口 8765 暂时被其他程序占用，正在自动重试」。服务会在后台按 1 秒到 15 秒的退避持续重绑，占用方一让开就恢复，不用重启 ClassIsland。

想立刻恢复就换一个端口。注意 Windows 有些端口段被系统保留（`netsh interface ipv4 show excludedportrange protocol=tcp` 可以查），撞上了换端口即可。

## 其他设备连不上

这是设计如此：服务只绑定 `localhost` 和 `127.0.0.1`，局域网里的其他机器连不上。需要跨设备时，用反向代理或内网穿透把请求转到本机 `8765`。

## 日志在哪

插件的错误日志只记它看得见的：请求被拒、发送提醒时抛的异常、监听中断与重绑失败。

- 文件位置：ClassIsland 插件配置目录下的 `error.log`
- 设置页 → 错误日志 → **打开日志文件** / **打开 ClassIsland 日志目录**
- 最多保留 100 条，新的在前

## 返回 500

响应里会带异常类型和原因，比如：

```json
{ "ok": false, "error": "内部错误：InvalidOperationException ..." }
```

同样的内容会写进插件错误日志。宿主语音服务内部的失败（Edge TTS 超时等）不会出现在这里，要去 ClassIsland 自己的日志里查。
